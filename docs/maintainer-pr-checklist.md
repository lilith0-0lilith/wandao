# 维护者 PR 验收清单

这份清单供维护者审核使用，不要求贡献者在默认 PR 模板中逐项填写。根据改动范围选择适用项，并把结论留在 PR 评论或维护记录中。

## 基础与安全

- [ ] 改动范围清晰，尽量只解决一个问题，并关联 Issue 或说明原因。
- [ ] 没有提交 Cookie、账号密码、App Secret、Token、API Key、私人知识库内容或未脱敏日志。
- [ ] 未通过路径、命令参数、网页内容或插件包引入越界写入、任意命令执行或凭证泄露。
- [ ] 依赖、许可证和第三方代码来源已检查。

## 代码与构建

- [ ] `python scripts/quality_check.py`
- [ ] `node scripts/validate_plugins.js`（涉及 `plugins/` 时）
- [ ] `python scripts/validate_providers.py`（涉及 Provider 或旧兼容目录时）
- [ ] Python 编译检查和桌面前端 JS 语法检查已通过。
- [ ] 涉及 `wandao_electron/src-tauri/` 时，使用 Rust 1.88.0、Tauri 2 完成 `cargo fmt --all -- --check`、`cargo test --all-targets --locked` 和 `cargo clippy --all-targets --locked -- -D warnings`。
- [ ] 发布资源、运行时和安装包检查已通过。

## 插件 / Provider 验收

仅对插件声明支持的能力验收；未声明或暂不支持的能力要明确记录。

- [ ] 导入 / 导出入口和实际操作界面可用。
- [ ] 登录方式、权限要求和凭证保存位置清楚。
- [ ] 目录结构没有重复、遗漏或错误父子关系。
- [ ] 图片已正确本地化、上传或保留链接；长内容不会被截断。
- [ ] 附件能下载、保留、上传，或给出明确的失败提示。
- [ ] 表格、代码块、引用、公式、嵌入等特殊格式的支持范围已验证。
- [ ] 失败项、资源警告、重试和最终任务报告可解释。
- [ ] 中断后 checkpoint 恢复不会重复写入或遗漏已完成内容。
- [ ] 联网、限流、429、风控和浏览器自动化行为符合平台限制。
- [ ] 并发、批量和请求间隔不会造成重复提交或绕过频率限制。
- [ ] 样例输入、输出、截图或录屏已脱敏并可复核。

## 桌面端、任务中心与 UI

- [ ] 成功、部分成功、失败、取消和可恢复状态的反馈清楚。
- [ ] 关键操作不会依赖阻塞式 `alert()` / `confirm()`。
- [ ] 键盘焦点、屏幕阅读器标签、错误关联和 reduced motion 行为正常。
- [ ] 长日志、图片、附件和失败项在任务中心中分开呈现。
- [ ] 旧 Provider、插件配置、历史任务和已有导出结果仍可读取。
- [ ] Windows 与 macOS 的路径、浏览器、权限和首次启动行为没有回归。

## 发布与回滚

- [ ] Release 文案按用户视角说明重点变化、升级建议和已知限制。
- [ ] 主程序与在线插件版本、下载资源和更新入口没有混淆。
- [ ] Windows / macOS 安装、升级、卸载和回滚已验证。
- [ ] 发布文件 SHA-256、运行时清单和插件注册表一致。
- [ ] 如需回滚，已确认旧版本仍可启动，且不会删除用户数据或导出目录。
